# codex-limit-watch

`codex-weekly` shows your current Codex 5-hour and weekly usage limits in the
terminal and refreshes them every minute.

```text
Codex limits

5-hour limit
[████████████████░░░░]  80% remaining · 20% used
Resets Jul 29, 2026, 4:42:00 PM (in 2h 25m)

Weekly limit
[██████████████░░░░░░]  72% remaining · 28% used
Resets Aug 5, 2026, 1:42:00 PM (in 6d 23h)

Plan: plus
Updated Jul 29, 2026, 2:17:00 PM

Refreshing every 60s · Ctrl-C to stop
```

## Requirements

- Node.js 18 or newer
- The [Codex CLI](https://developers.openai.com/codex/cli) installed and signed
  in with ChatGPT (`codex login status`)

The utility uses the local Codex app-server and your existing Codex login. It
does not read, store, or transmit your credentials itself.

## Run

Clone the repository, then:

```sh
node bin/codex-weekly.js
```

To make `codex-weekly` available globally:

```sh
npm link
codex-weekly
```

Press Ctrl-C to stop.

## Options

```text
--interval SECONDS  Set the refresh interval (default: 60)
--once              Print once and exit
--json              Print one machine-readable JSON result and exit
--no-clear          Do not clear the terminal between refreshes
-h, --help          Show help
```

Examples:

```sh
codex-weekly --once
codex-weekly --interval 30
codex-weekly --json | jq
```

## How it works

The CLI starts `codex app-server` as a child process, performs the documented
JSON-RPC initialization handshake, and requests `account/rateLimits/read`. It
selects the 300-minute and seven-day Codex rate-limit windows and displays the
percentage remaining and reset time for each. Both windows come from the same
request.

Codex may omit a window that is not active or available for the signed-in
account. In that case, the utility marks that window as unavailable instead of
guessing from another window.

The app-server protocol is generated by the installed Codex CLI, so upgrading
Codex is the first troubleshooting step if the protocol changes:

```sh
npm install -g @openai/codex@latest
```

## Development

No package installation is required.

```sh
npm test
node bin/codex-weekly.js --once
```
